# Fitness App  

### **Goal**:  
The aim is to create a fitness app that helps users calculate macros and track their nutrition in an easy and efficient way. The app is being built using Expo, React Native, and SQLite, with NativeBase handling the front end. A standout feature is the free barcode scanner, which makes saving and adding foods quick and hassle-free.  

### **Progress**:  
✅ **What’s Done:**  
- A clean and straightforward UI to save foods and add them to the daily counter.  
- A fully functional barcode scanner to simplify meal tracking.  

❌ **What’s Next:**  
- Adding a history feature to allow users to review and adjust their daily counter as needed.  

The app is nearing completion—around **90% finished**—and is shaping up to be a valuable aid for staying on track with your diet.
